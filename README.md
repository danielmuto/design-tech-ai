21 — SISTEMA DE PLACEHOLDERS



IMPORTANTE:



Todos os placeholders de imagem devem ser implementados como componentes ou áreas claramente identificadas no código.



Exemplo:



"<ImagePlaceholder type="hero" />"



"<ImagePlaceholder type="portfolio-01" />"



"<ImagePlaceholder type="daniel-portrait" />"



Não utilizar imagens aleatórias de banco de imagens para preencher esses espaços.



Cada placeholder deve apresentar visualmente:



- proporção correta;

- bordas;

- área de imagem;

- identificação temporária;

- comportamento responsivo.



Quando Daniel adicionar a imagem real, ela deverá ocupar exatamente o mesmo espaço sem quebrar o layout.
